# Ultron Assist

Sistema inteligente de asistencia escolar.

## Funciones

- 📋 Pase de lista
- ⚠️ Riesgo académico
- 📊 Estadísticas de asistencia
- 📁 Exportación a Excel
- 🤖 Integración futura con Ultron IA

## Riesgo académico

🟢 Bajo: 0-4 faltas

🟡 Medio: 5-9 faltas

🔴 Alto: 10 o más faltas

## Objetivo

Ayudar a docentes a registrar asistencia y detectar estudiantes en riesgo académico.
